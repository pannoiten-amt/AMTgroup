Phase 2 — Setup Project ใหญ่: ทะเบียนคุมพอร์ตงานลูกค้า

ต่อยอดจาก 15 ขั้นตอนจริงที่ทีมทำอยู่ (Phase 1) มาจัดกลุ่มเป็น 6 Gate สถานะ เพื่อใช้เป็นทะเบียนคุมภาพรวมพอร์ตลูกค้าทั้งหมด — ลูกค้า 1 ราย = 1 แถว ไล่สถานะผ่านแต่ละ Gate
เทียบกับมาตรฐาน 10 Phase เดิม: G1-G2 ครอบ Phase 1 (รับเอกสาร), G3 ครอบ Phase 2-5 (Planning ถึง Automated Check), G4 คือรอบตามเอกสารเพิ่มระหว่าง Phase 5-7, G5 ครอบ Phase 7-8 (Cross-Check + จัดทำ T1), G6 ครอบ Phase 9-10 (QC Review + พิมพ์ส่ง)
Gateรวมขั้นตอนเดิม (จาก Workflow Phase 1)สิ่งที่ทะเบียนคุมต้องบันทึกผู้รับผิดชอบ Gate
G1
ประสานขอเอกสาร		ขั้นตอน 1-3: เตรียมเลื่อนแท่ง → เช็ค DBD (หน้าทะเบียน) → รับ TB/GL/Detail รอบแรกวันที่ขอ / วันที่ได้รับรอบแรก / ครบหรือไม่ครบตูน
G2
บันทึกเข้าระบบ		ขั้นตอน 4: หยอดข้อมูลในทะเบียนคุมวันที่บันทึก / ผู้บันทึกตูน
G3
จัดทำ Draft		ขั้นตอน 5-7: Draft งบ T1-3 → Pending ขอเอกสาร → ส่งพี่มิ่งตรวจก่อนขอเอกสารเพิ่ม/สอบถามลูกค้าวันที่ Draft เสร็จ / รายการเอกสาร Pendingตูน → พี่มิ่ง
G4
วนรอบขอเอกสารเพิ่ม		ขั้นตอน 8-11: ส่งเมลครั้งที่ 1+โทร → รับรอบ 1 → ส่งเมลครั้งที่ 2+โทร → รับรอบ 2 (ครบ)รอบที่กำลังวน (1/2/3...) + วันที่ส่งเมลแต่ละรอบ
⚠ จุดที่งานค้างนานสุด — ควร Alert ถ้าเกิน 7 วันไม่ตอบ (เดิม Sheet รองรับแค่ 2 รอบ ควรเปิดให้ไม่จำกัดรอบ)		ตูน
G5
ยืนยันกับผู้สอบ		ขั้นตอน 12-13: ปริ้นงบคุยกับผู้สอบ → ส่งเมล Final Draft Confirm (T1-T3)วันที่คุยผู้สอบ / วันที่ลูกค้า Confirmพี่มิ่ง
G6
ปิดงาน		ขั้นตอน 14-15: ปริ้น Final ให้ผู้สอบลงนาม → ส่งงบ Final PDF + หนังสือรับรองผู้บริหารวันที่ลงนาม / วันที่ส่งจริง / เทียบ Deadline 30 เม.ย.พี่มิ่ง พี่นุช
มติที่ต้องตกลงวันนี้: รูปแบบทะเบียนคุม (Excel Dashboard แยกไฟล์ หรือฝังใน Google Sheet เดิม) และใครเป็นผู้ดูแล Dashboard ประจำวัน

Phase 3 — Update Work Flow: กระดาษทำการ 3 ชั้น

Map ขั้นตอนเดิมเข้ากับ 3 ชั้นกระดาษทำการที่ต้องสอดคล้อง TSA for LCE — พบว่า ชั้น 3 ยังเป็นช่องว่าง ต้องแทรกขั้นตอนใหม่เข้าไป
